# GiB 与 GB 等单位的转换问题

# 1. 两个标准

+ `十进制标准`: 由国际单位制 (`SI`) 指定;

  > 1999 年, 国际电工委员会 (IEC) 公布了修正 2:"IEC 60027-2: 电工技术应用的字母符号 -- 第二部分: 通信和电子.", 这个标准, 在 1998 年通过, 介绍了词头"kibi-
  > "," mebi-"," gibi-"," tebi-"," pebi-"," exbi-", 作为二进制乘幂的计数方法.

+ `二进制标准`: 由国际电工委员会 (`IEC`) 指定;

**十进制标准单位换算**(其中 `KB` 是 `kilobyte` 的缩写, 指的是 `千字节`)

```bash
1KB = 1000Byte
1MB = 1000KB
1GB = 1000MB
1TB = 1000GB
```

**二进制标准单位换算**(其中 `KiB` 是 `kilo binary byte` 的缩写, 指的是 `千位二进制字节`)

```bash
1KiB = 1024Byte
1MiB = 1024KiB
1GiB = 1024MiB
1TiB = 1024GiB
```

# 2. 磁盘容量问题

+ 硬盘制造商使用 `十进制标准`;
+ 电脑软件使用 `二进制标准`;

# 3. 大 B 与小 b

因为在网络传输的时候, 我们传输的实际上是一个个二进制数, 可以俗称为 `比特流`, 传输二进制数的时候不需要管这是什么字, 使用的什么编码, 我只管自己传输了多少二进制位, 因此在网络中, 我们普遍使用小 b 作为网络传输单位.
