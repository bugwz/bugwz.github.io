# Yum 源的优先级配置之 yum-priorities

# 1. 简介

Linux 发行版比较多, 同时还有很多个人或组织维护了某些特定用途的安装/升级源.**Yum Priorities** 插件可以用来强制保护源. 它通过给各个源设定不同的优先级, 使得系统管理员可以将某些源设定为最高优先级, 从而保证系统的稳定性.

# 2. yum-priorities

## 2.1 安装

```bash
yum install -y yum-priorities
```

## 2.2 配置验证

```bash
cat /etc/yum/pluginconf.d/product-id.conf
```

需要确认的是, 如果 `enabled` 的配置为 `1`, 代表已经启用了 yum 源的配置优先级;

```bash
[main]
enabled=1
```

## 2.3 配置优先级调整

```bash
[Example 1]
name=Example_1
baseurl=http://mirror.centos.org/centos/$releasever/example_1/$basearch/
priority=10
gpgcheck=0
enabled=1

[Example 2]
name=Example_2
baseurl=http://mirror.centos.org/centos/$releasever/example_2/$basearch/
priority=20
gpgcheck=0
enabled=1
```

关于上述配置的解释为:

+ 其中 `priority=N`,`N` 的值为:`1-99`, 当数字越大, 优先级越低;
+ 当 `Example_1` 与 `Example_2` 的源中存在同名同版本的软件包时, 优先安装 `Example_1` 中的安装包;
